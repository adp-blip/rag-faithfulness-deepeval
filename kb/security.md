# Security basics

All laptops must use full-disk encryption and lock automatically after 5 minutes idle.

Two-factor authentication is mandatory on Google Workspace, GitHub and Slack. Use the Okta Verify app; SMS codes are not allowed.

Never paste customer data into external AI tools. The approved internal assistant is LumenGPT, which runs on our own cloud account.

Report a lost or stolen device to security@lumenlabs.example within 1 hour, even outside working hours.

Passwords must be at least 14 characters and stored in 1Password. Password reuse across services is not allowed.
